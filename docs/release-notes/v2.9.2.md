## What's new in 2.9.2

A fix for the Teams autopilot, which approved the final OK of a task but never integrated it.

### Teams (Labs)

- **The autopilot integrates again**: the final OK arrives while the QA run that gave the verdict is still finishing its turn, and Integrar refuses to start while a run of the task is active. The autopilot took that answer as final and left every task in **Needs you** for you to integrate by hand, so a merge conflict or a failed verify never reached the Dev either. It now waits for that run to end and integrates then, with no notice in between.
- **One more try on a passing failure**: an integrate that failed because the base moved under it, the app closed in the middle or git timed out is tried once more before it waits for you. A merge conflict or a failed verify still goes back to the Dev, up to 3 times in a row.
