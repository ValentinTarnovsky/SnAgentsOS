## What's new in 2.2.1

Fixes for the desktop drawers and sidebar, Codex consoles, phone chat and phone mode, dictation and agent-to-agent messages. Your settings stay as they are (config schema 15, no upgrade step).

### Desktop

- **Files no longer moves the app**: opening Files with tabs already open used to slide the whole window sideways. Notes, Files and Changes now open over the grid without moving anything.
- **New console menu**: with Notes or Files open, the menu showed up behind the drawer. It now opens on top, and a click on the drawer closes it.
- **Compact usage**: the folded Usage panel is now a list with one row per limit (provider icon, bar and percent, red when you are close to the limit) instead of rings.
- **Collapsed sidebar**: the phone icon is centered, and the status dot sits beside each workspace icon instead of cutting into it.
- **Codex consoles stay in the sidebar**: a Codex console no longer vanishes from its workspace once it stops working. It shows Done or Idle like Claude, even with the Codex integration off.
- **History**: sessions from recent Codex versions get their titles again.

### Phone

- **Chat with Codex**: Codex consoles open in Chat too, even with the Codex integration off. If a chat is not available, the notice now tells you what to turn on for that agent.
- **"Open agent consoles in Chat" works**: a console that fell back to the terminal once no longer stays there, and turning the setting on or off resets the per-console choices.
- **Phone mode for every console**: the phone or PC fit button now applies to every console on this phone, and new consoles open the same way. The PC console only takes the phone's size while you are looking at it on the phone, and gets its size back as soon as you open another console or go Home (it used to wait 5 minutes). Typing on the PC still takes the size back.
- **Dictation**: pauses no longer capitalize every phrase ("Hola hola hola", not "Hola Hola Hola"), and a word that starts like the previous one is no longer cut.
- The app open on Home no longer gets a notification on top of its own alert.

### Agents and CLI

- **Messages between agents get sent**: the SnAgentsOS skill now tells Claude and Codex that follow-ups and replies to another agent need `--enter`, and how to ask the other agent to reply. `snaos send` without `--enter` now says "typed, not submitted".
