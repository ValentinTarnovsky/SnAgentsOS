## What's new in 2.5.0

Desktop dictation now runs a local Whisper model, Codex prompts sent from the phone are submitted again, Notes and Files remember their pin per workspace, and Type only works on agents running over SSH. Your settings move to config schema 18 by themselves: the dictation settings get their new defaults and the old engine choice is dropped.

### Dictation with Whisper (Windows)

- **A local Whisper model replaces the Windows recognizers**: dictation now uses whisper.cpp with the same Whisper models as desktop transcription tools. On an NVIDIA GPU it runs large-v3-turbo and each phrase is typed a fraction of a second after you stop talking. Without one it runs the small model on the CPU, one to two seconds per phrase.
- **Download once from Settings**: **Settings > Terminal > Dictation** shows the CPU pack (about 200 MB) and the GPU pack (about 1.8 GB, it includes the CPU pack), with progress, cancel and delete. Nothing is bundled in the installer. The first time on a GPU, preparing it takes up to a minute, right after the download.
- **Audio stays on this PC**: the model runs locally and nothing is sent to the internet.
- **Better with code**: add project names or commands under **Vocabulary** so words like `package.json` or `npm run typecheck` come out right. Silence and background noise no longer turn into invented phrases.
- **Device**: Automatic (GPU when its pack is downloaded, else CPU), GPU or CPU. If the GPU fails, dictation keeps working on the CPU and says so. A live preview of the phrase shows while you talk on the GPU.
- Text is still typed where the cursor is, on one line and never with Enter, and still waits for **Insert** while an agent waits on a permission or a menu is on screen.
- Needs the Microsoft Visual C++ 2015-2022 runtime (14.40 or later); when it is missing, the dictation overlay offers the download. Uninstalling SnAgentsOS keeps the downloaded packs: delete them from Settings first if you want the space back.

### Phone

- **Codex prompts are submitted again**: sending a prompt to a Codex console from the composer (Chat view or Terminal) left it typed but not sent. The Enter now reaches Codex as a submit. Custom Text keys with Enter and Quick Commands ending in a line break are fixed the same way.

### Desktop

- **Notes and Files per workspace**: each workspace keeps its own drawer, pin and maximized state. Pinning or opening a drawer on one workspace no longer closes or unpins the one on another.

### Share between PCs

- **Type only on agents over SSH**: a guest with **Type only** can now type into a Claude or Codex console that runs over SSH, where SnAgentsOS cannot read the agent's state. Enter and Ctrl+C stay blocked, and digits are refused while a numbered menu is on screen so a guest can never answer a permission.
