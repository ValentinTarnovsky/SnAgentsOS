## What's new in 2.1

Fixes and small features on top of 2.0.0. Your settings are upgraded automatically on the first start (config schema 14 to 15), with no step on your side.

### Sidebar

- **Collapsed sidebar**: icons sit on one axis, the "+" button fills the rail, keyboard focus shows a violet ring instead of the white default, and the usage rings are smaller.
- **Agents board button**: now next to "+ New workspace", and visible in the collapsed sidebar too. The board closes when you open any console or workspace (sidebar, palette, notifications).
- **Reorder workspaces**: drag a workspace to a new place. A line shows where it lands, and favorites and other workspaces only reorder among themselves. Works with the manual order.
- **Foldable usage panel**: the chevron next to Refresh folds the usage bars into one row of rings with their provider icon. The reset time is in each ring's tooltip.

### Usage bars

- **Codex**: usage now comes live from your ChatGPT account, so it also counts work done on other machines, in the Codex app or in the cloud. Windows are read by their length: a plan with only a weekly limit shows one Weekly bar instead of a wrong "Session". When the live source is not available, the local Codex session files are used, now picking the most recent data.
- **Claude**: fewer errors. Rate limits are respected with a longer wait between checks, an expired token is re-read before showing "Expired", and a failed check keeps the last good value (marked as out of date in the tooltip).

### Consoles

- **Smoother drag**: reordering consoles no longer flickers between two places when you hold one near the middle.
- **Move a console to another workspace**: from the console menu ("Move to workspace...") or by dragging its header onto a workspace in the sidebar. It is a view convenience for this session: after a restart, or when you reopen it after closing, it is back in its own workspace, and it keeps using its own folder and connection. A chip in its header takes it back.

### Git per console

- A workspace that holds many repos without being one (a folder of plugins, for example) now shows the repo of each console on its row in the sidebar: repo name, branch and +/- lines. The workspace row shows how many repos its consoles work in. PowerShell consoles follow your `cd`; agent consoles follow the folder the agent works in.

### Automation

- **SnAgentsOS skill for Codex**: Settings > Automation now installs the skill for Claude or for Codex, with a selector for which one (`~/.codex/skills/snagentsos`, honoring `CODEX_HOME`).
