## Rebrand

SnMultiCC is now **SnAgentsOS**. Same app, new name, and the upgrade is automatic: install 2.0.0 over 1.x (or accept the update from 1.14.1) and there is nothing else to do.

**What moves over.** On the first start SnAgentsOS copies everything from SnMultiCC into its own data folder: settings, workspaces, models, connection profiles, snippets, config backups and paired phones. Every file is checked against the original (SHA-256 and a full config parse) before anything old is touched. Paired phones keep their pairing and reconnect by themselves. Claude Code hooks are rewritten to the new names; hooks of other tools are left alone.

**What is deleted by itself.** Once the copy is verified, the app removes what SnMultiCC left behind, in the background: the old data folder, the old install folder and its entry in Settings > Apps (through the old uninstaller), the Start menu and desktop shortcuts, the old launch-on-startup entry (registered again for SnAgentsOS first, if it was on), the old notification registration, the updater cache, temporary files and the extraction of the 1.x portable, `~/.claude/settings.json.snmulticc.bak` and `%APPDATA%\snmulticc-dev`. The portable renames its own `.exe` to `SnAgentsOS-portable.exe` and deletes older `SnMultiCC-x.y.z-portable.exe` files next to it. On macOS `SnMultiCC.app` goes to the Trash. Files still in use are retried automatically. A one-time notice shows what came over and the cleanup status.

**30-day safety backup.** Before deleting anything, the app writes `migration-backup-v1.zip` in its data folder with your 1.x files exactly as they were, and verifies it. Settings > Data shows where it is and when it goes away: it is deleted automatically 30 days after the migration. The README explains how to recover from it in a disaster (quit, copy `config.json` and `remote-devices.json` back, start).

**Firewall.** The old Windows firewall rule for `SnMultiCC.exe` stays behind, inert (removing it needs admin rights). With remote control on, Windows asks for permission for SnAgentsOS once: allow it on private networks and your phones reconnect.

**Taskbar pin.** If your pin survives the upgrade, it is pointed to SnAgentsOS. If the old uninstaller removed it, the notice asks you to pin SnAgentsOS again (Windows does not let apps pin themselves).

**Rolling back to 1.x is not supported.** The old data folder no longer exists, so a reinstalled 1.14.1 starts empty. Keep the backup zip if you want a copy of your 1.x settings.

**Also worth knowing.** Consoles now export `SNAOS_CONSOLE_ID` and `SNAOS_PTY_ID` instead of the old `SNMULTICC_*` names; update any script of yours that reads them. On Linux, remove the old package with `sudo apt remove snmulticc`. A home-screen app added on iOS keeps the old name until you add it again.

## What's new in 2.0

2.0.0 is the big update: everything the roadmap had planned for later versions ships together in this release. Your settings are upgraded automatically on the first start (config schema 11 to 14), with no step on your side.

### Mobile

- **Home first**: the phone opens on a Home with a Resume card, one section per workspace, agent state per console, a waiting pill and a "+" button to create workspaces.
- **Docked composer**: write the whole prompt with drafts, chunked delivery and safe paste, or switch to Direct input to type straight into the console.
- **Answer cards**: answer Claude's permissions ("Allow", "Always allow"), AskUserQuestion wizards and the Plan card with a tap, with no typing in the terminal.
- **Chat view**: read an agent console as a chat built from its transcript, next to the raw terminal.
- **Phone-fit**: a phone can size a console to its own screen; the PC keeps its size and gets it back with Recover.
- **Notifications**: Web Push to the locked phone in secure mode (HTTPS through `tailscale serve`), plus an ntfy channel and an "only when I am away from the PC" gate.
- **Work tools**: Changes screen with paged diffs and review notes, History with search and resume, image attach, Quick Commands sheet and the workspace note and Automations screen.
- **Usable terminal**: text selection with Copy, tap to open URLs and paths on the PC, momentum scroll, pinch to zoom and a "New lines" pill.
- **KeyBar**: keys fire on release with auto-repeat, and a Key bar screen lets you reorder keys and build your own.
- **Reliable connection**: a connection state machine with a tiered banner, offline input guard, connection log, Diagnostics screen and a Windows firewall check with a one-click fix.
- **Phone extras**: pane tabs with long-press actions, Claude exited strip with Resume, cache countdown, keep screen on, clipboard paste and a live QR scanner.

### Agents

- **Waiting for you**: `Ctrl+K` opens on the consoles that wait for you (`Ctrl+1..6` picks one) and `Ctrl+Shift+J` jumps to the next one.
- **Resume**: agent sessions are remembered, resumed on launch and after a restart, with a resume dialog on startup and "Claude exited" chips.
- **Richer status**: per-agent sidebar rows, state durations, last reply, current tool and pending requests in fast tooltips, with Codex detail from its App Server.
- **Agents board**: `Ctrl+Shift+A` shows every agent console as a board; idle agents can hibernate and wake up resumed.
- **Agent race**: send the global prompt to several agents at once, each in its own worktree, and follow them on a race bar.
- **Keep awake**: the PC stays awake while agents work, with a title bar indicator.

### Terminal

- **Saved history**: console scrollback survives a restart of the app, with trash on close.
- **Exit card**: a console that exits shows its code and restarts in place, keeping its history.
- **Headless mirror**: reattach and phone replay draw from a background mirror, so a reload or a reconnect keeps the screen exact.
- **Unicode 11 widths** for emoji and box drawing on the desktop, the phone and the mirror (Settings > Terminal).
- **PowerShell shell integration**: prompt marks, jumps between prompts (`Ctrl+Shift+PageUp/PageDown`), a bar with the exit code of each command and copy of a command's output.
- **Drag and drop**: dropped files and images are pasted in the format each console understands.

### Git

- **Git chip**: branch and change counts in the workspace header, the sidebar and the phone (Settings > Git).
- **Changes panel**: `Ctrl+Shift+D` opens a drawer with the changed files, a unified diff and review notes you send to a console in one paste.
- **Worktrees**: launch a console in its own git worktree, with a branch chip, a close dialog and orphan cleanup.

### Automation and CLI

- **Quick Commands**: saved prompts and actions per workspace or global, in a `Ctrl+Shift+Q` popover, in `Ctrl+K` and on the phone (replaces snippets).
- **`snaos` CLI**: inside every console, `snaos ls`, `open`, `spawn`, `send`, `read`, `wait`, `status`, `notify` and `note` drive the app; `snaos help --agent` teaches it to agents.
- **`.snagentsos.json`**: a repo can bring its own consoles, grid, setup and Quick Commands, trusted by hash before anything runs; export and reload from the workspace menu.
- **Automations**: recurring schedules per console (daily, weekdays, weekly, hourly) that wait for the agent to be free, with a history, "Run now" and a table in Settings > Automation.
- **Workspace composer**: one card to create a workspace (`Ctrl+Enter`), plus a note and a task state per workspace.

### Desktop comfort

- **Toasts**: a toast stack for confirmations, in-app agent cards and notices of actions taken from a phone.
- **Update card**: available updates show in the toast stack and a title bar chip, with the list of versions you skipped.
- **Crash recovery**: error boundaries, automatic renderer recovery, a crash log and "Copy diagnostics".
- **Open in SnAgentsOS**: an Explorer context menu entry (Settings toggle) opens a folder in its workspace or prefills the wizard.
- **Faster settings**: per-row search (`Ctrl+F`) with deep links, KeyHint chips on primary buttons and keyboard-first wizards.
- **Focus shortcuts**: `Ctrl+1..9` focuses a console, `Ctrl+Alt+Left/Right` moves between consoles and `Ctrl+Shift+U` reopens the last closed one.

## Updates

- The built-in updater now refuses any download that has no `.sha256` checksum next to it.
- Releases are published only once all 16 files (8 builds and their checksums) are attached, so an update never sees a half-uploaded release.

## Terminal rendering check (mojibake)

Emoji and box drawing now use Unicode 11 widths (Settings > Terminal, on by default) on the desktop, the phone and the background mirror. The renderer policy does not change: Canvas stays the default, WebGL stays opt-in and the automatic redraw is the same. This release ships only after this manual pass, run on the installed build with the default settings, desktop and phone:

- [ ] Settings > Terminal shows the Canvas renderer selected (no WebGL) on a clean profile.
- [ ] Desktop, 6 Claude panes busy: put the PC to sleep and wake it; no garbled glyphs in any pane.
- [ ] Desktop: lock Windows and unlock it, then alt-tab through the 6 panes; no garbled glyphs.
- [ ] Desktop: a real Claude session that prints emoji and box drawing, then `/exit`; the text after an emoji stays in its column and the "Claude exited" chip shows.
- [ ] Desktop: turning Unicode 11 off and on redraws the panes live, without a restart.
- [ ] Phone (iOS and Android): the same Claude output looks the same as on the desktop, emoji included.
- [ ] Phone: lock and unlock the phone, and wake the PC from sleep with the phone connected; the terminal comes back without garbled glyphs.
