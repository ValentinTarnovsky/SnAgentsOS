## What's new in 2.2

Notes and Files for every workspace, agent states you can trust when agents drive other agents, voice and a better chat on the phone, and Codex on par with Claude. Your settings stay as they are (config schema 15, no upgrade step).

### Agent states

- **Drivers no longer fool the app**: a `claude -p` started from a console (a driver script like `sn-drive.sh`, a sub-task) is now tracked as a sub-session of that console. It never replaces the console's own Claude, never shows "Claude exited" and keeps the console "Waiting" while it runs.
- **Waiting instead of Done**: when a turn ends with subagents, a `snaos wait` or a driver still running, the console shows a violet hourglass and "Waiting" instead of Done, sends no "turn finished" notice and does not hibernate. A dev server running in the background does not hold it: it shows Done with "N in the background".
- **Turns the agent starts on its own** (a background task came back) notify again when they end.
- **Esc**: interrupting a turn no longer leaves the console stuck in "Working".
- **"Claude exited"** only shows when Claude really left: with the catch-all exit reason it waits for your shell prompt to come back.
- **One notice per question**: a question or a plan used to count as two requests (badge "2" and a double notice). It is one now, and the workspace badge counts consoles that need you.
- The SnAgentsOS skill teaches Claude and Codex how to wait on other consoles and drivers.

### Codex

- **"Codex exited [Resume] [New]"** after you quit Codex, on the desktop and on the phone. Resume types `codex resume <thread>`.
- Review notes can open a new Codex console when that is your default agent (or when there is no Claude preset).

### Phone

- **Chat right away**: a console you just created opens in Chat with an empty conversation, and the messages show up as soon as the first one is written. A /clear does the same instead of falling back to the terminal.
- **Dictation**: a mic button next to the composer, the prompt to every console, the new console prompt and note editing. The words go where the cursor is, never with Enter, so it works the same in SSH consoles. It needs the secure (https) address; on the plain address it tells you so and offers it. The language is in Settings.
- **Notes**: open a workspace's notes from its menu on Home, read them as Markdown, edit them (with dictation) and create new ones.
- The workspace list follows the sidebar order: favorites first, your drag order, or the smart order.

### Desktop

- **Notes (Ctrl+Shift+M)**: Markdown notes per workspace for plans, todo lists and context for the agents. Edit, split or preview, saved as you type, and "Insert path" puts the note's path in the console so an agent can read it. They are real `.md` files on your PC; deleted notes stay in their trash for 30 days.
- **Files (Ctrl+Shift+E)**: the workspace folder as a tree, with tabs and a code editor (syntax colors for the usual languages, Ctrl+S, find and replace, multiple cursors). When an agent changes a file you have open, a clean tab reloads by itself and one with edits asks you. Windows line endings and BOMs are kept, and unsaved changes come back after a restart. Right click for new, rename, move to trash, copy path, insert path into the console and show in the file manager.
- Changes, Notes and Files share the right side of the workspace: one at a time.
- The agents board opens with the idle column expanded.
